# Phishing-Website-Detection-Using-ML
The goal of this project is to make a detection model which will detect the phishing websites depending on various factors, using machine learning algorithms.

Objectives:
Detect phishing websites using machine learning.
Compare the performance of multiple classification algorithms.
Evaluate models using standard performance metrics.
Identify the best-performing model for phishing website detection.

Machine Learning Algorithms Used:-
Logistic Regression
K-Nearest Neighbors (KNN)
Decision Tree
Random Forest
Support Vector Machine (SVM)
AdaBoost
Gradient Boosting

Technologies Used:-
Python
Jupyter Notebook
NumPy
Pandas
Matplotlib
Scikit-learn
Mlxtend

Workflow:-
Data Loading
Data Preprocessing
Feature Selection
Train-Test Split
Model Training
Prediction
Model Evaluation
Performance Comparison
Decision Boundary Visualization
Best Model Selection

Evaluation Metrics:-
Accuracy
Precision
Recall
F1-Score
Confusion Matrix
Classification Report
Results

Among all the implemented models, Random Forest achieved the highest classification accuracy, making it the most effective model for phishing website detection on this dataset. 
Other algorithms were compared to analyze their strengths and weaknesses in classifying phishing websites.
